# 文章模板

把下面内容复制到 `src/content/blog/你的文件名.md`。文件名建议使用小写英文和连字符。

````markdown
---
title: "文章标题"
description: "用一两句话概括文章内容。"
pubDate: "2026-09-17T20:00:00+08:00"
category: "随笔"
draft: true
# cover: "images/cover.jpg"
---

## 第一部分

正文从这里开始。

## 第二部分

可以使用 **粗体**、_斜体_、[链接](https://example.com) 和列表：

- 第一项
- 第二项

也可以插入代码：

```js
console.log("Hello");
```

> 这里是一段引用。
````

写完并预览无误后，将 `draft: true` 改为 `draft: false`，然后提交和推送。
