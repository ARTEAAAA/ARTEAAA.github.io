## 用标题组织思路

Markdown 是一种轻量的文本标记方式。用井号表示标题层级，就能让一篇文章拥有清晰的结构。

```markdown
## 问题背景

### 已经尝试的方法

## 最后的解决方案
```

文章本身已经有主标题，正文通常从二级标题开始。避免仅仅为了改变文字大小而跳过层级。

## 让列表承担合适的工作

步骤适合有序列表，并列的要点适合无序列表。真正需要展开的理由，仍然值得用完整的段落来说明。

- 一项只表达一个主要意思。
- 保持各项的语气和长度相近。
- 列表太长时，尝试重新组织主题。

## 留下可以复现的代码

代码块后注明语言，可以让语法高亮更准确。除了代码，也应说明运行环境和预期结果。

```javascript
const notes = ["观察", "实践", "记录"];
console.log(notes.join(" → "));
```

行文中的变量名可以使用行内代码，例如 `notes`。比起贴出整段日志，保留最相关的几行通常更容易理解。

## 发布前再读一遍

检查链接是否可以打开，图片有没有合适的说明，代码是否还能运行。删掉重复的句子，让读者更快找到重点。
